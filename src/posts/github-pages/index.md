## GitHub Pages 배포

GitHub Pages는 GitHub 저장소에서 정적 웹사이트를 호스팅할 수 있는 서비스입니다.

### 주요 특징

- **무료 호스팅**: 공개 저장소에 대해 무료로 제공
- **자동 배포**: Git push 시 자동으로 배포
- **커스텀 도메인**: 사용자 정의 도메인 연결 가능
- **HTTPS 지원**: SSL 인증서 자동 제공

### 배포 방법

1. 저장소 설정에서 Pages 활성화
2. 소스 브랜치 선택 (보통 main 또는 gh-pages)
3. 빌드 설정 구성
4. 자동 배포 대기
